# Data

The competition files are not redistributed in this repository.

After accepting the competition rules, download the data with the Kaggle CLI:

```bash
kaggle competitions download -c playground-series-s6e7
unzip playground-series-s6e7.zip -d data
```

Expected files:

```text
data/train.csv
data/test.csv
data/sample_submission.csv
```

Competition page: <https://www.kaggle.com/competitions/playground-series-s6e7>
